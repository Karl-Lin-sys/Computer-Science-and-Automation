# Computer Science and Automation Doctoral Program

**Institution**: Ilmenau University of Technology (TU Ilmenau)
**Location**: Ilmenau, Germany
**Taught In**: English
**Duration**: 3 years

## Overview
Ilmenau University of Technology beckons aspiring scholars to explore its distinguished doctoral program in Computer Science and Automation. This program offers a gateway to cutting-edge research and innovation.

### Epistemological Framework
This curriculum is strictly grounded in an evidence-based framework:
- **Top-tier Synthetic Evidence**: Relying only on Meta-Analyses and Systematic Reviews published within the last 3 years.
- **Primary Evidence**: Relying only on Randomized Controlled Trials (RCTs) published within the last 20 years.
- **Bias Mitigation**: Explicit structural safeguards are implemented to eliminate cognitive biases, particularly the **Fundamental Attribution Error**, ensuring objective assessment of both algorithmic and human-system interactions.

## Modules
1. Artificial Intelligence and Machine Learning
2. Robotics and Autonomous Systems
3. Computer Vision and Image Processing
4. Software Engineering and Systems
5. Cybersecurity and Privacy
